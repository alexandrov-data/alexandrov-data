## Избранные проекты

### 1. Анализ маркетинговых метрик
**LTV, CAC, ROI, когортный анализ, окупаемость рекламы**

Проект по маркетинговой аналитике и оценке эффективности привлечения пользователей.  
В работе рассчитаны ключевые метрики юнит-экономики, проведён когортный анализ, исследованы рекламные каналы, конверсия и удержание пользователей.  
Цель проекта — выявить причины неокупаемости рекламы и подготовить рекомендации по перераспределению маркетингового бюджета.  
[Открыть проект](https://github.com/alexandrov-data/marketing-metrics-ltv-cac-roi)

### 2.Прогнозирование оттока клиентов фитнес-клуба
**Машинное обучение, EDA, классификация, сегментация клиентов**

Проект по применению методов машинного обучения для прогнозирования оттока клиентов фитнес-клуба.
В работе проведён исследовательский анализ данных, сравнены модели классификации для предсказания ухода клиентов и выполнена сегментация клиентской базы по уровню риска.
Использованы логистическая регрессия, случайный лес и кластеризация.  
[Открыть проект](https://github.com/alexandrov-data/customer-churn-prediction-ml)

### 3. Приоритизация гипотез и анализ A/B-теста
**ICE, RICE, кумулятивные метрики, статистическая проверка**

Проект по приоритизации продуктовых гипотез и анализу результатов A/B-теста интернет-магазина.  
В работе гипотезы были ранжированы с помощью ICE и RICE, затем проанализированы кумулятивные метрики эксперимента, выявлены выбросы и проверена статистическая значимость различий между группами.  
Цель проекта — показать, как принимать продуктовые решения на основе данных и результатов эксперимента.  
 [Открыть проект](https://github.com/alexandrov-data/ab-testing-hypothesis-prioritization)

### 4. Статистический анализ данных сервиса аренды самокатов
**t-тесты, распределения, вероятностные расчёты**

Проект по применению методов статистического анализа на данных сервиса аренды самокатов.  
В работе выполнены предобработка и объединение данных, исследование распределений, сравнение пользователей разных тарифов, проверка статистических гипотез и решение прикладных задач по теории вероятностей.  
Цель проекта — показать применение статистических методов для анализа пользовательского поведения и поддержки бизнес-решений.  

[Открыть проект](https://github.com/alexandrov-data/scooter-rental-statistical-analysis)
